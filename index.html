Model Pinger

Open a platform, paste your API key, pick a model and press Ping. Green means it replied. Red means it did not.

You are viewing this page in a preview or from a file on your computer. Browsers block the platforms from here, so every ping will fail. Upload it to GitHub and open the live link instead.
